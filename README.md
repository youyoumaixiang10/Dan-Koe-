# Dan Koe 思想应用

`apply-dan-koe-frameworks` 是一套基于可追溯资料构建的 AI Skill，用于把 Dan Koe 关于个人成长、Human 3.0、一人公司、内容系统、个人品牌与写作的思想，转化为可以分析真实问题的决策框架。

它不是 Dan Koe 的电子分身，也不负责模仿他的口吻。它会区分 Dan Koe 的明确观点、方法、个人自述、宣传主张、第三方理论与 AI 归纳，并保留材料缺口、观点变化和适用边界。

## 它从哪里来

原始知识库母体约有 1297 份资料。经过多轮检索、去重和深读，重点整理约 70 份关键文件，归并成 30 个可追溯来源条目，最终形成 11 个可调用决策框架。

## 11 个决策框架

1. 反愿景—愿景决策
2. 问题优先级
3. 目标作为决策镜头
4. Human 3.0 四象限扫描
5. False Transformation 检查
6. 身份阻力分析
7. 心理熵与挑战—技能匹配
8. 个人问题 → 专属知识
9. Niche of One
10. MVO 与产品化
11. 内容选题与复用

## 使用方式

下载本仓库，将包含 `SKILL.md` 的完整目录导入支持 Skills 的 AI 工具，或放入对应工具的 Skills 目录。

示例：

```text
使用 $apply-dan-koe-frameworks，结合我有稳定工作、孩子和房贷的现实，分析我是否适合做一人公司，并给出低风险起步方案。
```

```text
使用 $apply-dan-koe-frameworks，帮我做一次 Human 3.0 启发式四象限扫描，但不要冒充官方测试。
```

```text
使用 $apply-dan-koe-frameworks，根据 Dan Koe 不同时期的内容工作流，为我设计公众号和 X 的内容复用系统。
```

## 重要边界

- Human 3.0 仅作为启发式自我反思框架，不冒充官方 Assessment。
- 不把 Dan Koe 的商业数据和个人经历当作普遍结果保证。
- 不用成长框架替代心理健康、医疗或其他专业建议。
- 不冒充 Dan Koe 本人，也不伪造引语。

本项目为非官方整理，与 Dan Koe 本人无隶属或授权关系。
